Preguntas frecuentes

Resolvemos tus dudas

¿Qué es Zernio y para qué sirve? +

Zernio es una plataforma de automatización de redes sociales que te permite conectar tus cuentas de Twitter/X, Reddit, LinkedIn, Instagram y Facebook, y programar posts automáticamente. Incluye una API REST para developers que quieran integrarlo en sus propias aplicaciones o scripts.

¿Es difícil de configurar? +

No, el proceso toma menos de 2 minutos: creas una cuenta, conectas tus perfiles via OAuth y ya puedes programar tu primer post. No se requieren conocimientos técnicos para usar el panel visual.

¿Zernio tiene API para developers? +

Sí. Zernio ofrece una API REST con autenticación Bearer. Puedes publicar en cualquier plataforma conectada, programar posts y gestionar cuentas directamente desde Python, Node.js o cualquier lenguaje con soporte HTTP. Disponible en planes Pro y Business.

¿Hay versión gratuita? +

Sí, el plan gratuito permite hasta 10 posts/mes en 2 plataformas, sin necesidad de tarjeta de crédito. Es perfecto para probar la herramienta antes de comprometerte con un plan de pago.

¿Es seguro conectar mis cuentas? +

Sí. Zernio usa OAuth 2.0 para conectar tus cuentas, lo que significa que nunca almacena tus contraseñas. La autenticación pasa por los sistemas oficiales de cada plataforma, con los mismos estándares de seguridad que usan las apps más populares del mercado.

¿Qué plataformas soporta Zernio? +

Actualmente Twitter/X, Reddit, LinkedIn, Instagram y Facebook. El equipo trabaja continuamente en agregar nuevas plataformas como TikTok, YouTube y Threads.
